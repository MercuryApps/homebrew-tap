# Homebrew Tap

Homebrew casks for apps by [ashrinkm](https://github.com/ashrinkm).

```bash
brew tap ashrinkm/tap
brew trust ashrinkm/tap
brew install --cask video-audio-converter
```

`brew trust` is a one-time step Homebrew asks for with any tap outside its official repositories.

| Cask | Description |
|------|-------------|
| [video-audio-converter](https://github.com/ashrinkm/video-audio-converter) | Free video and audio converter for Mac |
